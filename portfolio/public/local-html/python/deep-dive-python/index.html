Ghi nhớ nhanh

Ba quyết định kỹ thuật xuất hiện thường xuyên nhất.

Async

Không để CPU ngồi chờ khi đang đợi I/O. Mạnh nhất với network, database, file và API.

Thread

Hợp khi phải dùng thư viện đồng bộ như requests, boto3 hoặc SDK cũ mà vẫn cần chạy nhiều I/O.

Process

Dùng khi cần chạy CPU song song thật. Mỗi process có GIL riêng nên vượt được giới hạn của thread.
